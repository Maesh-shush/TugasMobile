TugasMobile

Student Management Mobile Application

About the Application

TugasMobile is a student management mobile application developed as part of an academic project. The application demonstrates mobile application development using React Native, Expo, and Firebase.

Features

  • Google account authentication.
  • Persistent login session.
  • Student data storage using Firebase Firestore.
  • Display student information from the database.
