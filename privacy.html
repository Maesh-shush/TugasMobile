Privacy Policy

TugasMobile - Student Management Application

1. Introduction

This Privacy Policy explains how TugasMobile collects, uses, and handles information when users access the application.

TugasMobile is an academic project developed for educational purposes.

2. Information We Collect

When users sign in using Google Authentication, the application may access basic profile information, including:

  • Name
  • Email address
  • Profile picture

The application may also process student information stored in its Firebase database.

3. How We Use Information

Information is used for the following purposes:

  • Authenticating users through Google.
  • Maintaining login sessions.
  • Displaying basic user profile information.
  • Managing and displaying student records.

4. Data Storage

Authentication and application data are processed using Firebase services, including Firebase Authentication and Cloud Firestore.

Authentication session information may be stored locally on the user's device.

5. Data Sharing

We do not sell users' personal information. Information may be processed by Google and Firebase as necessary to provide authentication and database services.

6. Data Security

We rely on available Firebase security features and appropriate database access rules to help protect stored information.

No method of electronic storage or transmission is completely secure.

7. Changes to This Policy

This Privacy Policy may be updated when application features or data handling practices change.
